R41N Brute Force Lab

R41N Brute Force Lab is a Python-based cybersecurity project that demonstrates how brute-force password attacks work in a controlled, local testing environment. The project helps users understand password security, password guessing, and the importance of protecting accounts against unauthorized access.

The program simulates password-guessing attempts and measures the number of attempts and time required to find a matching password. It also demonstrates SHA-256 hash comparisons and includes automated unit tests to verify that key features work correctly.

Features

Password Guessing Simulation: Demonstrates brute-force concepts in a controlled environment.

SHA-256 Hash Comparisons: Shows how password hashes can be compared.

Attempt Tracking: Tracks the number of guesses made during a simulation.

Runtime Measurement: Measures how long a simulation takes.

Automated Testing: Includes unit tests to check program functionality.

Educational Focus: Explains password security and responsible cybersecurity practices.

Project Goal

The goal of this project is to build practical Python programming skills, explore fundamental cybersecurity concepts, and understand why strong passwords and defensive security measures are important.
